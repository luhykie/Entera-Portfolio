# Portfolio – Lyka Mae L. Entera

A one-page portfolio. Everything lives in `index.html`.

## Deploy on GitHub Pages (free)

1. Sign in at github.com and click **New repository**.
2. Name it `YOUR-USERNAME.github.io` (replace with your exact GitHub username). Set it to **Public**, then click **Create repository**.
3. Click **uploading an existing file**, drag in `index.html` and `README.md`, then **Commit changes**.
4. Go to **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, then **Save**.
5. Wait 1–2 minutes. Your site will be live at `https://YOUR-USERNAME.github.io`.
6. Put that link in your CV.

If you name the repo something else (e.g. `portfolio`), the link becomes `https://YOUR-USERNAME.github.io/portfolio`.

## Before you publish

Search `index.html` for `TODO` and `YOUR-USERNAME` and fill those in:

- Replace `YOUR-USERNAME` in the GitHub button with your real username.
- Add a sentence about what **Biyahero** does, plus its tech stack and repo link.
- Add tech tags for **CONEXIA**.
- Add LinkedIn if you have one.

## Add a new project

Copy one `<article class="card">…</article>` block in the Projects section, paste it below the last one, and edit the text. To add a link, put this line above the tags:

```html
<a class="link" href="https://github.com/YOUR-USERNAME/REPO" target="_blank" rel="noopener">View on GitHub →</a>
```

## Editing later

On GitHub, open `index.html`, click the pencil icon, edit, and commit. The site updates in about a minute.
